# Recommendation System Project

## 프로젝트 개요
이 프로젝트는 여행 추천 시스템을 구축하는 것을 목표로 합니다. 여행자와 여행지 데이터를 기반으로 여행자에게 다음 여행지를 추천하는 시스템을 개발합니다.

## 주요 구성 요소

### 데이터베이스
- PostgreSQL을 사용하여 여행자, 여행, 방문지 정보를 저장합니다.
- 주요 테이블: `traveller`, `travel`, `travel_purpose`, `visit_area_info`.

### 전처리
- 여행 로그 데이터를 전처리하여 모델 학습에 적합한 형식으로 변환합니다.
- 성별, 여행 상태, 여행 목적 등을 인코딩하고, PCA를 사용하여 특성을 축소합니다.

### 추천 시스템
- 그래프 신경망(GNN)을 활용하여 여행자와 여행지 간의 관계를 학습합니다.
- 모델은 여행자와 여행지 간의 유사도를 계산하고 점수를 예측합니다.

### API
- FastAPI를 사용하여 추천 시스템을 서비스로 제공합니다.
- 외부에서 추천 요청을 받아 처리할 수 있습니다.

### MLFlow
- 머신러닝 실험을 관리하고 추적하는 플랫폼입니다.
- PostgreSQL을 백엔드 스토어로, MinIO를 아티팩트 저장소로 사용합니다.

## 실행 방법
1. Docker Compose를 사용하여 모든 서비스를 실행합니다.
2. FastAPI를 통해 API 요청을 보내고 추천 결과를 확인합니다.
3. MLFlow UI를 통해 실험 결과를 추적하고 관리합니다.
